# Monster Meatball - Icon Design Specification

## Style Guide
- **Art Style:** Osamu Tezuka inspired manga
- **Line Weight:** Bold, 3-4px outlines
- **Colors:** Flat, vibrant, high contrast
- **Size:** 128x128px standard, scalable to 512x512px
- **Format:** PNG with transparency

---

## Kill State Icons (Corner Markers)

### Clean Kill - 🗡️
- Simple straight sword
- Vertical orientation
- Silver/gray blade
- No motion lines
- Clean, precise aesthetic

### Rushed Kill - 🗡️~
- Same sword as Clean
- Single curved motion line (blue/white)
- Suggests speed
- Slightly tilted angle

### Brutal Kill - 🛠️
- Heavy war hammer
- Dark metal (gray/black)
- Two impact wave lines (red/orange)
- Dramatic but cartoonish

## Background Patterns

### Card Backgrounds
- **Monster Cards:** Subtle terrain texture (forest, mountain, sea, sky)
- **Dish Cards:** Parchment/recipe scroll texture
- **Tool Cards:** Weathered metal or wood grain
- **Character Cards:** Subtle action lines

### Color Coding
- **Red Meat Monsters:** Warm red border
- **White Meat Monsters:** Cool cream border
- **Exotic Meat Monsters:** Purple shimmer border
- **Sea Meat Monsters:** Blue-teal border

---

## Accessibility Notes
- All icons must work in grayscale
- Avoid red-green only distinctions
- Use shape + color coding
- High contrast ratios (4.5:1 minimum)
- Clear silhouettes at small sizes
